ReMD WELLNESS WEBSITE PROTOTYPE
================================
Open index.html to preview in a browser. Upload all HTML files and the assets/ directory together to your web host.

IMPORTANT BEFORE LAUNCH
1. Verify the physician board certification statements and exact naming of issuing organizations, as well as QME status. These were supplied by the practice.
2. Verify main practice ZIP 94583 and all addresses. Verify office hours and which services are offered in each location.
3. Confirm service descriptions, procedures and insurance/referral acceptance. The site intentionally avoids assuming specific procedures or coverage.
4. Replace AI-generated illustrative image crops with licensed professional photographs if preferred. Avoid implying the models are actual patients.
5. Register your actual domain and set absolute canonical URLs and OpenGraph image URLs, XML sitemap hostname and Google Search Console. No domain was provided, so no domain was fabricated.
6. Publish a tailored privacy policy, accessibility statement, cookies details if needed, and HIPAA-appropriate contact/scheduling workflows. Do not collect clinical histories through ordinary website contact forms.
7. Configure a real appointment system or form only with appropriate protections; currently all appointment buttons call the office.
8. Check structured data with Google's Rich Results Test and Schema.org validator, verify search indexing and page speed.
9. Browser page titles and meta descriptions are implemented on each page. Visible FAQ answers mirror FAQPage structured data, but Google does not guarantee FAQ rich results.
10. The original approved logo is retained as the PNG master, and all other images ship locally.
